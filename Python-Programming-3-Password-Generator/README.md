# Python Programming Task 3 - Password Generator

## About the Project

This project is a Password Generator created using Python for my Oasis Infobyte Python Programming Internship.

The program helps users create random passwords by allowing them to choose the password length and the types of characters they want to include.

It is a command-line project that helped me practice Python basics and user input handling.

## How the Program Works

The program asks the user to enter the required password length.

The user can also choose which types of characters should be included in the password, such as:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

After receiving the user's choices, the program generates a random password according to the selected requirements.

The generated password is then displayed on the screen.

## Features

- Allows the user to choose the password length.
- Generates random passwords.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Checks the user's input.
- Displays the generated password.
- Allows the user to generate another password.

## Technologies Used

- Python 3
- random module
- string module

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run the following command:

   python password_generator.py

5. Enter the required password length.
6. Select the character types you want to include.
7. The program will generate and display a password.
