# Python Programming Task 2 - BMI Calculator
# About the Project

This is a simple BMI Calculator created using Python for my Oasis Infobyte Python Programming Internship.

The program asks the user to enter their weight and height. It then calculates the Body Mass Index (BMI) and displays the result along with the BMI category.

## How the Program Works

First, the user enters their weight in kilograms and height in meters.

The program uses this formula to calculate BMI:

BMI = Weight / (Height × Height)

After calculating the BMI, the program displays the result and tells the user whether they are underweight, normal weight, overweight, or obese.

## Features

- Takes weight as input from the user.
- Takes height as input from the user.
- Calculates BMI using Python.
- Displays the calculated BMI.
- Shows the related BMI category.
- Runs through the command line.

## BMI Categories

The BMI result is divided into these categories:

- Below 18.5: Underweight
- 18.5 to 24.9: Normal weight
- 25 to 29.9: Overweight
- 30 or above: Obese

## Technologies Used

- Python 3

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code or any terminal.
3. Run the following command:

   python bmi_calculator.py

4. Enter your weight and height when the program asks.
5. The program will display your BMI result.
