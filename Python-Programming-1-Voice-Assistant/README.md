# Python Programming Task 1 - Voice Assistant
## About the Project

This is a simple Voice Assistant created using Python for my Oasis Infobyte Python Programming Internship.

The purpose of this project is to create a basic assistant that can listen to the user's commands and respond accordingly. It uses Python to take voice input and perform different tasks based on the given command.

## How the Program Works

The program starts by greeting the user.

It then listens to the user's voice command and processes it. According to the command, the assistant gives a response or performs the required task.

The assistant can handle basic commands and provide a simple voice-based interaction with the user.

## Features

- Greets the user.
- Takes voice commands.
- Converts voice input into text.
- Responds to the user's commands.
- Performs basic assistant tasks.
- Uses text-to-speech for responses.

## Technologies Used

- Python 3
- Speech Recognition
- Text-to-Speech

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run the following command:

   python voice_assistant.py

5. Speak a command when the assistant asks.
6. The assistant will respond according to the command.
