# Python Programming Task 4 - Basic Weather App

## About the Project

This project is a Basic Weather App created using Python for my Oasis Infobyte Python Programming Internship.

The program asks the user to enter a city name and then uses a weather API to get the current weather information for that location.

It displays useful details such as temperature, humidity, weather condition, and wind speed.

## How the Program Works

First, the user enters the name of a city.

The program sends a request to the weather API and receives the weather information in JSON format.

After processing the response, it displays the current weather details for the selected city.

## Features

- Takes a city name from the user.
- Fetches current weather information.
- Displays temperature in Celsius and Fahrenheit.
- Displays humidity.
- Shows the current weather condition.
- Displays wind speed.
- Handles invalid city names and API errors.

## Technologies Used

- Python 3
- Requests library
- JSON
- OpenWeatherMap API

## How to Run

1. Make sure Python is installed on your computer.
2. Install the required library:

   pip install requests

3. Add your weather API key to the Python file.
4. Open the project folder in VS Code.
5. Run the following command:

   python weather_app.py

6. Enter a city name when the program asks.
7. The current weather information will be displayed.
